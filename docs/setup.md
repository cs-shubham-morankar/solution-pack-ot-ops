# Installation

1. To install a solution pack, click **Content Hub** > **Discover**.
2. From the list of solution packs that appears, search for **oTOps**.
3. Click the **oTOps** solution pack card.
4. Click **Install** on the bottom to begin installation.

## Prerequisites

- None

# Configuration

For optimal performance of the **oTOps** solution pack, install and configure the following connectors:

- A ticketing and workflow management connector to retrieve, update, and manage service requests and tasks.
    - To configure and use the ServiceNow connector for task management and workflow automation, refer
      to [Configuring ServiceNow Connector](https://docs.fortinet.com/document/fortisoar/3.6.0/servicenow/360/servicenow-v3-6-0#Configuration_parameters).
- An identity and access management connector to retrieve and manage users and groups within the organization.
    - To configure and use the FortiAuthenticator connector for user provisioning and group management, refer
      to [Configuring FortiAuthenticator Connector](https://docs.fortinet.com/document/fortisoar/1.0.0/fortinet-fortiauthenticator/320/fortinet-fortiauthenticator-v1-0-0#Configuration_parameters).
